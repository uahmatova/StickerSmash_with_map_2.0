# StickerSmash_with_map_2.0

1. Мобильное приложение StikerSmash, в котором пользователь может прикреплять изображение/фотографию, редактировать и выгружать.
2. Был добавлен раздел для работы с картой. Пользователь может ставить метки на карте и прикреплять/удалять фотографии у каждой метки.
3. Все метки и изображения теперь хранятся в базе данных

## Установка и запуск
### требования
- Node.js 
- Установленное приложение Expo Go на мобильном устройстве для тестирования

### шаги для установки
1. Клонировать репозиторий:
   git clone https://github.com/uahmatova/StickerSmash_with_map_2.0.git
2. Установить зависимости с помощью команды npm install
3. Перейти в папку репозитория
4. Запустить npx expo start
